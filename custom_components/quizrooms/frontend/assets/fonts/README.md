| `quizrooms-arabic-bold.woff` | `QuizArabic` (600–800) | DejaVu Sans Bold | Bitstream Vera / DejaVu Fonts License |
| `quizrooms-mono.woff` | `QuizMono` | Google Noto Sans Mono | SIL Open Font License 1.1 (OFL-1.1) |
